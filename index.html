Mekanisme Auto-Folder Drive

  • Struktur Otomatis: File dikelompokkan ke direktori My Drive / [Proyek] / [Kategori].

Koneksi Akun Google Drive Pribadi

Agar file tersimpan otomatis langsung ke Google Drive Anda, hubungkan menggunakan Google Cloud API OAuth Client ID atau gunakan metode Apps Script Webhook.

Masukkan URL Web App Google Apps Script untuk integrasi real file.

Panduan Ringkas Setup Google Apps Script:

  1. Buka script.google.com dan buat proyek baru.
  2. Gunakan fungsi skrip penerima file base64 untuk otomatis membuat folder Proyek/Kategori di Drive Anda.
  3. Deploy sebagai Web App (akses: "Anyone") lalu tempel URL-nya di atas.
